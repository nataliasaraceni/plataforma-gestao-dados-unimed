# Plataforma de Gestão de Dados — Unimed (protótipo)

Protótipo navegável da plataforma de gestão de dados dos contratos Unimed (Arpen Analytics). Serve para mostrar a ideia, a navegação e as interações da plataforma.

## Como abrir
1. Clique em **`Plataforma_Ideal_Mockup.html`** acima.
2. Clique em **Download raw file** (ícone de download, no canto direito).
3. Abra o arquivo baixado com dois cliques — ele roda no navegador, é um arquivo único e funciona offline.

> **Dados ilustrativos** — os números são exemplos para demonstrar a leitura e as interações; serão substituídos pelos dados reais da Unimed.
